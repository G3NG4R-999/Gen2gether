# Gen2gether Architecture

Gen2gether is a small multiplayer layer for Gen2Recomped.

## Goals

- See other players in the overworld.
- Move together in real time.
- Players collide with each other.
- Simple keyboard chat.
- Keep the vanilla Gen2Recomp experience intact.

## Non-goals for the first version

- MMO systems
- GTS
- Trading
- PvP
- Accounts
- Quests
- Online saves

## Architecture

Client
  ↓
Gen2gether multiplayer layer
  ↓
Gen2gether server
  ↓
Other clients
